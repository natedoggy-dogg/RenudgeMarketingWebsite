# Wordmark

The product's wordmark as the dashboard spec defines it: a `nudge` square at radius 5px, then "reNudge" at 700 with " it" at 400 in `ink-subtle`, set in the `product` family.

- Use the small size (15px, 18px square) in the nav and footer, the large size (30px, 34px square) only on the 404 page and social cards.
- It is set in type, not an image. There is no designed logo file yet; don't draw one or substitute an icon.
- In running copy write `renudge.it`, not the wordmark spelling.
- Never place it inside a client-page mockup: client pages are white-labelled.
- Consumer provides: nothing but a link target (`/`).
