# CadenceTimeline

The chasing schedule as a day track (outline dots for email, filled for SMS, a warning dot where it hands over to a person) plus the plain-English sentence the product itself uses.

- The sentence is the point, as in the product: real days and a real first name beat a preset name.
- Must match the product's actual default cadence. Today the copy draft and the dashboard spec disagree; use whatever the planner ships.
- Always state the send time and timezone rule in the eyebrow.
- Consumer provides: the stops (day, channel) and the sentence.
