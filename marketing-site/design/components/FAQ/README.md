# FAQ

Native `details`/`summary` rows between hairlines, a mono plus/minus, answers in muted body copy.

- Questions in the buyer's words, answers that start with "Yes" or "No" where they can.
- Every FAQ block also emits `FAQPage` JSON-LD from the same data, so the copy and the structured data can't diverge.
- Answers on the page are the source; don't paraphrase them in the schema.
- Consumer provides: a list of question and answer pairs.
