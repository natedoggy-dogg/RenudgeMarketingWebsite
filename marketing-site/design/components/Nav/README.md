# Nav

The site header: wordmark, at most four links, a quiet "Sign in" and one primary "Start free".

- Four links maximum at launch: Product, Templates, Pricing, Security. Add "Customers" only once a real case study exists.
- The nav's "Start free" is the page's primary button until the hero's appears; never add a second primary in the nav.
- Below 720px the links collapse into a menu button; "Start free" stays visible.
- Consumer provides: the link list and the signup URL (which carries `?template=<slug>` on template pages).
