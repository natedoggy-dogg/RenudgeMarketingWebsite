# ReplyToData

The differentiator in one picture: a casual SMS with the extracted phrases highlighted, an arrow, and the structured fields they landed in. Use it in the homepage hero area and Product section 5.

- The outbound message names the business and states the ask plainly, exactly as the composer would.
- The inbound message is casual and believable: lowercase, a contraction, an approximate figure. Two values in one message shows the "pulled apart and filed separately" behaviour.
- Field labels are operator labels from a real template (here: Mortgage Pre-Approval). Values are formatted cleanly (currency, dates).
- The meta line says where the value came from. If a value would overwrite a committed one, show "staged · waiting for you" with the warning badge instead of "confirmed".
- Uses the fictional operator Riverside Mortgages; never a real firm.
- Consumer provides: operator name, client first name, the outbound ask, the inbound reply with marked spans, and the field list (label, value, provenance).
