# ChecklistCard

The full checklist on a `/templates/[slug]` page: title and count in the head, then one row per item with the client-facing wording, a kind chip and required/optional.

- This is the template page's SEO substance; show every item, never behind a signup.
- Item titles and descriptions are the client-facing wording from the task library, not internal operator labels. Generate them from the library so the page can't drift from what the product sends.
- Counts in the head derive from the rows.
- Healthcare, legal and mortgage templates need a practitioner review before publishing.
- Consumer provides: template title, and items (client label, client instruction, kind, data type, required).
