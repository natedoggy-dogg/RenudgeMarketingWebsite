# CTABand

The closing call to action on the page's one `night` band: a `display-l` headline, a single supporting line, primary and on-night secondary buttons.

- Once per page, at the end. It is the only dark surface on a page.
- The supporting line states the next step's size ("in minutes"), not a benefit recap.
- Primary keeps its `nudge` fill on night; the secondary uses `.rn-btn-on-night`.
- Consumer provides: headline, supporting line, two CTAs.
