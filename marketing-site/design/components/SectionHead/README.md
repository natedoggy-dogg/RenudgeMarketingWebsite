# SectionHead

Opens a section: a `rule` hairline, a mono `eyebrow` in a 64px margin column (a section number or a short label), the `display-m` headline and a muted intro.

- The hairline is the section divider. Don't also change the band colour at the same boundary.
- Use numbers ("02") on long pages that read top to bottom (Product page), labels ("THE PROBLEM") elsewhere.
- Headline ≤ 12 words, intro ≤ 60ch.
- Consumer provides: eyebrow text, headline, optional intro.
