# VerifiedNote

A bordered note for comparison pages that carries a "last verified" date, the source, and an honest concession.

- Every `/vs/` page opens its table with one, and includes a "where they're stronger" note. A rigged comparison costs more than it earns.
- The date and source come from the comparison's frontmatter; the build warns when a date is more than 90 days old.
- Bordered on all four sides in `rule-strong`. Never a coloured left border.
- Consumer provides: verified date, source description, and the note.
