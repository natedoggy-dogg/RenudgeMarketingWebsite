# PhoneFrame

A phone body holding a white-labelled client page: the operator's initials square and name, the sized ask, progress, and the checklist with one "next up" card. It shows what the client sees, so renudge.it never appears inside it.

- Always a fictional operator: Altogether Ventures (`operator-berry`, accountancy) or Riverside Mortgages (`operator-teal`, mortgage). Swap the accent by overriding `--operator-berry` usage in the consumer's markup.
- Copy comes from the product's client copy rules: name the business in the headline, size the ask, "nothing is lost".
- Long lists use the product's long-list treatment: completed items collapsed into one row, one raised "next up" card, the rest quiet.
- Pair it with copy about the client's experience (no account, no app), not about the operator's dashboard.
- Consumer provides: operator name and initials, client first name, the summary line, progress and task rows.
